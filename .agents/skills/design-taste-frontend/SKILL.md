# Project Frontend Design

1. Read design.md. Inspect the affected page, shared components, CSS tokens, and available assets before choosing a composition.
2. Identify the page's audience, message, proof, and primary CTA from the brief and existing content. Preserve established brand and page intent unless the requested redesign changes them.
3. Compose around that content: use hierarchy, spacing, and real project evidence instead of adding decorative filler or invented metrics.
4. Implement with existing Astro components and CSS. Consult ARCHITECTURE.md for data/browser boundaries or lifecycle changes; inspect package.json before adding dependencies.
5. Check the affected page at desktop and mobile widths, including Portuguese wrapping, CTA visibility, imagery, focus states, and any changed interaction. Follow design.md for accessibility and motion.
6. Run the checks required by AGENTS.md. For navigation or interaction changes, verify direct load and Barba navigation.

Completion: the requested page works at the checked widths and interaction states, fits the project design, and passes the relevant checks.
